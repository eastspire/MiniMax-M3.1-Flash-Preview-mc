Cubeworld

an endless seeded voxel world, drawn entirely in code

  1. Terrain, caves, ores and eight climates, all from one seed
  2. Mine anything; place any of twenty-three block types
  3. No assets are downloaded — every texture is painted at load

Pointer lock is requested for mouse look. If it is refused, drag with the left button to look around instead.
